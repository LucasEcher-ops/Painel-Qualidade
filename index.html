Painel Qualidade

Um painel integrado ao WMS para reunir User List Auto, User Access e Cubi-Scan em um só lugar, com filtros operacionais e atualização central automática.

Como funciona a instalação?

São três passos simples. Instale o Tampermonkey, instale o Loader do Painel Qualidade e abra o WMS. O Loader é instalado uma única vez e busca automaticamente a versão atual do painel.

Central 2.5.6 · Loader 1.0.4
1

Instalar a extensão necessária

Instale o Tampermonkey no Chrome. Se ele já estiver instalado, siga direto para o passo 2.

Instalar extensão
2

Instalar o Painel Qualidade

Clique no botão e, na tela do Tampermonkey, confirme em “Instalar”. Atualizações futuras chegam pelo próprio Loader.

Instalar painel
3

Abrir o WMS

Após a instalação, abra o WMS e aguarde o carregamento. O menu “Painel Qualidade” aparecerá automaticamente.

Abrir WMS

Se algo não funcionar

  • Confirme se o Tampermonkey está instalado e ativado.
  • Em Extensões do Chrome, ative “Permitir scripts de usuário” para o Tampermonkey.
  • Se a opção não aparecer, ative o “Modo do desenvolvedor” na tela de extensões.
  • Depois da instalação, atualize o WMS com Ctrl + F5 e aguarde alguns segundos.
  • Se o painel já estiver instalado, clicar novamente em “Instalar painel” atualiza o Loader.
